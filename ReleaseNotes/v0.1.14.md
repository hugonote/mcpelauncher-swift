# Minecraft Bedrock Launcher 0.1.14

- Simplified the launcher status UI, Touch Bar layout, and download button labels.
- Replaced segmented Settings controls with compact menus and refined the layout and descriptions.
- First-time setup now verifies Minecraft ownership before downloading the runtime.
- Play now reinstalls Minecraft automatically when installed game files are missing.
- Fixed launcher integrity checks.
- Fixed unexpected system alert sounds when typing during Google sign-in.
- Fixed a separate Dock icon appearing during Xbox sign-in.
- Removed icons from the Game menu.
- Adopted Liquid Glass button styles on macOS 26 and newer.
- Reduced background process linger on macOS 27.
- Simplified the Homebrew installation command.
